Справочник Мага C++

1. Вывод данных (std::cout)

Используется для вывода текста или переменных в консоль. Требует библиотеки <iostream>.

#include <iostream>

std::cout << "Привет, Мир!" << std::endl; // std::endl делает перенос строки

2. Переменные и Типы Данных

  • int - целые числа (напр. 10, -5)
  • double - числа с плавающей точкой (напр. 3.14, 0.5)
  • std::string - строки текста (напр. "Hero")
  • bool - логический тип (true или false)
int hp = 100;
double mana = 50.5;
std::string name = "Mage";
bool isAlive = true;

3. Ввод данных (std::cin)

Считывает значение с клавиатуры и записывает в переменную (использует стрелочки >>).

int age;
std::cin >> age; // Ввод числа от пользователя

4. Условия (if / else)

if (hp > 0) {
    std::cout << "Герой жив!";
} else {
    std::cout << "Герой повержен!";
}

5. Циклы (for / while)

// Цикл for исполняется определенное число раз
for (int i = 0; i < 3; i++) {
    std::cout << "Удар мечём №" << i << std::endl;
}
