Шпаргалка Базового C++

1. Математика (<cmath>)

std::pow(2, 3) = 8 (степень), std::sqrt(16) = 4 (корень), std::abs(-5) = 5 (модуль), std::max(a, b) и std::min(a, b).

2. Функции (Functions)

int add(int a, int b) { return a + b; } — функция с возвращаемым значением. void printMsg() — функция без возврата значения.

3. Строки (std::string)

s.length() или s.size() — длина строки, s[0] — первый символ, s.substr(pos, len) — подстрока, s.push_back('!') — добавить символ.

4. Символы (char & <cctype>)

std::toupper(c) — в верхний регистр, std::tolower(c) — в нижний, std::isdigit(c) — проверка на цифру, std::isalpha(c) — проверка на букву.

5. Векторы (std::vector)

std::vector<int> v; — динамический массив. v.push_back(10); — добавить в конец, v.pop_back(); — удалить последний, v.size() — размер массива.

6. Множества (std::set)

std::set<int> s; — хранит только уникальные упорядоченные элементы! s.insert(5); — добавить, s.erase(5); — удалить, s.count(5) — возвращает 1, если элемент есть, иначе 0.
