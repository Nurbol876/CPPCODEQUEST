# Code Quest: C++ Hero

Небольшая браузерная игра-тренажёр по основам C++. Игрок проходит уровни, решает задания с кодом и побеждает противников правильными ответами.

## Запуск

1. Откройте файл [index.html](index.html) в браузере.
2. Выберите уровень на главном экране.
3. Проходите испытания по порядку.

Для работы внешних шрифтов и иконок требуется подключение к интернету, так как проект использует CDN Google Fonts, Font Awesome и Tailwind CSS.

## Уровни

| Порядок | Файл | Содержание |
| --- | --- | --- |
| 1 | [1.html](1.html) | Первые команды и базовый синтаксис C++ |
| 2 | [2.html](2.html) | Переменные, условия, циклы и дополнительные задания |
| 3 | [3.html](3.html) | Математика, функции и основные вычисления |

## Возможности

- интерактивные задания по C++;
- игровая система уровней и противников;
- очки здоровья, опыт, золото и зелья;
- подсказки Духа Компилятора;
- справочник по синтаксису C++;
- звуковые эффекты;
- переход на главную страницу из любого уровня;
- экран победы с возможностью начать игру заново или вернуться в меню.
