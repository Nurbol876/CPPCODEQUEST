Справочник Мага C++

1. Вывод и Переменные

std::cout << "Text"; выводит текст. Типы: int (целые), double (дробные), char ('a'), bool (true/false), std::string ("текст").

2. Ввод и Условия

std::cin >> x; считывает ввод. if (условие) { } else if { } else { }. Логика: && (И), || (ИЛИ), ! (НЕ).

3. Циклы

for(int i=0; i<N; i++), while(условие), do-while. Команды break (выход) и continue (следующая итерация).

4. Массивы и Строки

int arr[3] = {10, 20, 30}; Доступ по индексу c 0: arr[0]. Для std::string: str.size() или str.length().

5. Функции и Указатели

int add(int a, int b) { return a + b; }. Ссылка: int &ref = x;. Указатель: int *ptr = &x; (хранит адрес памяти).
